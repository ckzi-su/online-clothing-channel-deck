## 발표자 노트에 둘 내용
- S02: 통계표 ID, 조회기간, 자료다운일자, 잠정치 표기.
- S03: 국면 구분 기준(3~6월 / 7~8월)은 분석자가 정한 것이며, 통계적 구분점이 아님.
- S06: 8월 역전이 있으므로 "병행몰이 항상 더 강하다"로 일반화하지 않는다.
- S07: 기여도 = 각 채널 감소액 / 전체 감소액.
- S09: 산점도는 규모와 비중의 관계를 보여 줄 뿐 인과가 아니다.
- S10–S13: 가설과 사실을 문장에서 구분한다. "데이터는 ~를 보여 준다 / ~일 수 있다".
- S14: 날씨·계절성·프로모션·소비심리는 이 표에 없다. 원인 주장 금지.
- S15: 2026-07 의복 계의 1백만 원 불일치도 각주로 언급 가능.
