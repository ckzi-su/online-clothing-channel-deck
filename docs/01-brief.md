# 01. 프로젝트 브리프

## 주제
온라인 전용 쇼핑몰과 온·오프라인 병행 쇼핑몰의 **의류 거래** 비교.

## 리서치 질문
1. 2026년 3~8월 의류 온라인 거래액은 두 운영형태에서 각각 어떻게 변했는가?
2. 두 채널의 상대적 점유율 변화는 다른 상품군과 비교해 어떤 특징이 있는가?
3. 이 차이를 설명할 수 있는 요인은 무엇이며, 데이터가 말해 주지 않는 것은 무엇인가?

## 잠정 가설 (검증 전, 슬라이드에서는 "가설"로 표시)
- H1. 의류는 다른 상품군보다 병행몰 의존도가 높다.
- H2. 7~8월 거래액 감소 국면에서 병행몰의 상대적 방어력이 더 크다.
- H3. 그 차이는 오프라인 접점(피팅·교환·반품)과 브랜드 신뢰에서 설명될 수 있다.
  → H3은 통계만으로 검증 불가. 별도 문헌/사례 근거가 있을 때만 주장으로 승격.

## 범위
| 항목 | 내용 |
|---|---|
| 기간 | 2026년 3월 ~ 8월 (7·8월 잠정치) |
| 공간 | 전국 |
| 상품군 | 의복(주 분석), 가방·신발·패션용품 등 패션 인접군(비교) |
| 채널 정의 | 온라인 전용몰 / 온·오프라인 병행몰 (둘 다 **온라인 거래액**) |
| 단위 | 백만 원 |
| 원자료 | KOSIS DT_1KE10051 「온라인쇼핑동향조사」 [R01] |

## 반드시 지킬 해석 경계
- 이 통계의 '병행몰'은 **오프라인 매출이 아니다.** 오프라인 매장을 운영하는
  사업체의 온라인 거래액이다. "오프라인 매출이 더 잘 나왔다"는 식의 해석 금지.
- 7·8월은 `p)` 잠정치다. 증감률을 말할 때도 잠정치임을 함께 표시한다.
- 6개월 비교로 계절성·구조적 추세를 단정하지 않는다. 원인은 가설로만 제시한다.
- 의류 거래액 감소의 원인(날씨, 소비심리, 프로모션 일정 등)은 현재 데이터에 없다.

## 청중과 산출물
- 청중: **데이터 분석을 처음 배우는 대학 비전공자** (입문 수업).
- 산출물: 16:9 HTML 슬라이드 덱. 전체 18장(`S00–S17`) + 하이라이트 샘플 6장(`H00–H05`).
- 발표 시간·장수: **15분 내외 / 18장** (사용자 요청으로 확대, 조정 가능).
- 모션: anime.js(브라우저), seaborn(정적 백업 차트), Manim(히어로 영상).
- 디자인: FIGMA(`DESIGN.md`) / PPT(종이 질감) 두 컨셉을 토글로 제공.

## 성공 기준
- 모든 수치가 `data/processed/` CSV와 일치한다.
- 모든 사실 주장에 `[R{NN}]`가 있고, `sources.json`에 등록되어 있다.
- "온라인 거래만 집계"라는 한계가 덱에서 최소 1회 명시된다.
- 슬라이드마다 메시지가 하나이고, 3초 안에 읽힌다.
- 16:9 레이아웃이 깨지지 않고, 출처 표기가 빠지지 않는다.
- 비전공자가 처음 보는 용어(거래액·점유율·증감률·p))를 슬라이드 안에서 풀어 준다.
- 모션이 실패해도 정적 상태로 읽힌다(`prefers-reduced-motion` 존중).
