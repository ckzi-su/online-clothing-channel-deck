# Data — 원자료와 가공 데이터

## 원자료
- **파일:** `data/raw/온라인쇼핑몰_운영형태별_상품군별거래액_20261025005845.xlsx`
- **출처:** 국가데이터처, 「온라인쇼핑동향조사」, KOSIS 통계표 DT_1KE10051 [R01]
- **조회기간:** 2026-03 ~ 2026-08 (7·8월 잠정치 `p)`)
- **다운로드:** 2026-10-25 00:58
- **단위:** 백만 원
- 원본은 **수정하지 않는다.** 모든 가공은 `scripts/`에서 수행한다.

## 가공 데이터
| 파일 | 내용 | 사용처 |
|---|---|---|
| `processed/clothing_monthly.csv` | 의복, 월×채널 long format | 검산·차트 데이터 |
| `processed/clothing_wide.csv` | 의복, 월별 전용/병행/계 + 점유율 | S03–S05 |
| `processed/category_latest.csv` | 2026-08 p) 상품군별 전용/병행/계 + 병행몰 비중 | S01, S06 |

### 컬럼 정의
- `month`: `YYYY-MM`
- `provisional`: 해당 월이 잠정치이면 `True`
- `channel`: `계`, `온라인 전용몰`, `온·오프라인 병행몰`
- `value_million_krw`: 거래액(백만 원)
- `online_share_pct`, `omni_share_pct`: `계` 대비 비중(%), 소수 둘째 자리 반올림
- `category`, `subcategory`: 상품군 분류. `category_latest.csv`는 `subcategory=소계`만 포함.

## 재현
```bash
python3 scripts/xlsx_to_csv.py
```
- 표준 라이브러리만 사용 (openpyxl 불필요).
- xlsx를 직접 파싱해 `xl/worksheets/sheet1.xml`, `xl/sharedStrings.xml`을 읽는다.

## 검증 결과 (2026-10-25)
- 의복 `전용몰 + 병행몰 = 계`: 6개월 중 5개월 일치.
- **2026-07만 1백만 원 불일치** (878,232 + 765,895 = 1,644,127 vs 표의 계 1,644,126).
  원자료의 반올림/잠정치 처리로 보이며, **원자료 값을 수정하지 않고 그대로 사용**한다.
  차트에서는 `계`를 별도 계산하지 말고 표의 `계`를 쓴다.
- 2026-08 상품군 23개 합계 = 표의 합계 24,211,791 (일치).

## 해석 주의
- **온라인 거래만** 집계한다. '병행몰'은 오프라인 매출이 아니다.
- 7·8월은 잠정치다. 증감률·순위를 말할 때 잠정치 표기를 함께 쓴다.
- 6개월 자료다. 계절성·구조적 추세를 단정하지 않는다.
- 2026-07의 1백만 원 불일치는 분석 결론에 영향이 없지만, 각주에 남길 수 있다.
- 원자료의 `합계`는 서비스업을 포함하므로, 상품군 비교 시 `합계`를 기준선으로만 쓴다.
